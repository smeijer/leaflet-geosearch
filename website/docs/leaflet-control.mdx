# Leaflet Control

To show the search control on your leaflet map, add the `SearchControl` to the leaflet map

<Map provider="OpenStreetMap" />

```js
import { SearchControl, OpenStreetMapProvider } from 'leaflet-geosearch';

const searchControl = new SearchControl({
  provider: new OpenStreetMapProvider(),
  style: 'bar',
});

map.addControl(searchControl);
```

## Style

<Map provider="OpenStreetMap" controlOptions={{ style: 'button' }} />

```js
import { SearchControl, OpenStreetMapProvider } from 'leaflet-geosearch';

const searchControl = new SearchControl({
  style: 'button',
  provider: new OpenStreetMapProvider(),
});

map.addControl(searchControl);
```

## Several providers

With `providers` instead of `provider`, a select left of the input lets the user pick the provider to search with, or search all of them at once. In that case every suggestion shows the name of its provider. Picking another provider searches the typed text again.

<Map providers={['OpenStreetMap', 'Photon', 'Esri']} />

```js
import {
  SearchControl,
  OpenStreetMapProvider,
  PhotonProvider,
  EsriProvider,
} from 'leaflet-geosearch';

const searchControl = new SearchControl({
  providers: [
    { label: 'OpenStreetMap', provider: new OpenStreetMapProvider() },
    { label: 'Photon', provider: new PhotonProvider() },
    { label: 'Esri', provider: new EsriProvider() },
  ],
  allProvidersLabel: 'All', // false leaves the "all" option out
  style: 'bar',
});

map.addControl(searchControl);
```

The labels are only shown to the user, so they can be in any language. When one provider fails while searching all of them, the others still show their results.

### How many suggestions

`maxSuggestions` (default `5`) is the size of the whole list, not the number per provider. When all providers are searched, they take turns: the first result of each provider, then the second of each, and so on, until the list is full. With the three providers above and the default of 5, that's 2 from OpenStreetMap, 2 from Photon and 1 from Esri.

For the same number from each provider, set `maxSuggestions` to a multiple of the number of providers:

<Map
  providers={['OpenStreetMap', 'Photon', 'Esri']}
  controlOptions={{ maxSuggestions: 9 }}
/>

```js
const searchControl = new SearchControl({
  providers: [
    { label: 'OpenStreetMap', provider: new OpenStreetMapProvider() },
    { label: 'Photon', provider: new PhotonProvider() },
    { label: 'Esri', provider: new EsriProvider() },
  ],
  maxSuggestions: 9, // up to 3 from each provider
});
```

A provider with fewer results leaves its turns to the others. With a single provider selected, the list shows up to `maxSuggestions` of its results.

### Falling back to another provider

`fallback` searches the next provider in the list when the selected one fails (`'error'`), or also when it finds nothing (`'empty'`). With the select hidden, the user sees a single search box that keeps working when the first provider is down:

<Map
  providers={['OpenStreetMap', 'Photon']}
  controlOptions={{
    showProviderSelect: false,
    allProvidersLabel: false,
    fallback: 'error',
  }}
/>

```js
const searchControl = new SearchControl({
  providers: [
    { label: 'OpenStreetMap', provider: new OpenStreetMapProvider() },
    { label: 'Photon', provider: new PhotonProvider() },
  ],
  showProviderSelect: false,
  allProvidersLabel: false,
  fallback: 'error',
});
```

### From code

```js
searchControl.selectProvider(1); // the index in providers, or 'all'
searchControl.getSelectedProvider(); // { index: 1, label: 'Photon', provider }
searchControl.setProviderSelectVisible(false);

map.on('geosearch/providerchange', ({ provider }) => {
  console.log(`searching with ${provider.label}`);
});
```

`resultFormat`, `popupFormat` and the events also get the provider that found a result, e.g. `resultFormat: ({ result, provider }) => ...`.

## Zoom on a result

Results with bounds (most OpenStreetMap results) are fitted into the map, results without bounds are shown at `zoomLevel`. `zoomToBounds: false` shows every result at `zoomLevel`, `fitBoundsOptions` goes to Leaflet's `fitBounds`.

<Map
  provider="OpenStreetMap"
  controlOptions={{ zoomToBounds: false, zoomLevel: 16 }}
/>

```js
const searchControl = new SearchControl({
  provider: new OpenStreetMapProvider(),
  zoomToBounds: false,
  zoomLevel: 16,
  // or keep fitting the bounds, but not too close and away from the edges
  // fitBoundsOptions: { maxZoom: 16, padding: [50, 50] },
});
```

## Events

| Event                      | Payload                              | When                                                          |
| -------------------------- | ------------------------------------ | ------------------------------------------------------------- |
| `geosearch/showlocation`   | `{ location, marker, provider }`     | A result is shown on the map.                                 |
| `geosearch/marker/dragend` | `{ location, event }`                | A draggable result marker was moved.                          |
| `geosearch/error`          | `{ error, query, source, provider }` | A search failed. `source` is `'autocomplete'` or `'submit'`.  |
| `geosearch/providerchange` | `{ provider }`                       | Another provider was picked, by the user or `selectProvider`. |

### geosearch/showlocation

`location` is the result as the provider returned it, `marker` the Leaflet marker on the map, and `provider` the provider that found the result. With a single `provider`, its label is `''`.

```js
map.on('geosearch/showlocation', ({ location, marker, provider }) => {
  console.log(JSON.stringify({ location, provider: provider.label }, null, 2));
});
```

```json
{
  "location": {
    "x": 4.2990429,
    "y": 52.0990969,
    "label": "Madurodam, 1, George Maduroplein, Archipelbuurt, The Hague, South Holland, Netherlands, 2584RZ, The Netherlands",
    "bounds": [
      [52.0990469, 4.2989929],
      [52.0991469, 4.2990929]
    ],
    "raw": {
      "place_id": 275030941,
      "osm_type": "node",
      "osm_id": 2590910713,
      "class": "tourism",
      "type": "theme_park"
    }
  },
  "provider": "OpenStreetMap"
}
```

`x` is the longitude and `y` the latitude. `raw` is the full answer of the provider, shortened here.

### geosearch/marker/dragend

Only with `marker: { draggable: true }`. `location` is the new position of the marker, `event` the Leaflet dragend event.

```js
map.on('geosearch/marker/dragend', ({ location, event }) => {
  console.log(JSON.stringify(location, null, 2));
});
```

```json
{
  "lat": 52.0993,
  "lng": 4.3001
}
```

### geosearch/error

`error` is what the provider threw, `query` the searched text, `source` either `'autocomplete'` or `'submit'`, and `provider` the provider that failed.

```js
map.on('geosearch/error', ({ error, query, source, provider }) => {
  console.log(
    JSON.stringify(
      {
        message: error.message,
        query,
        source,
        provider: provider.label,
      },
      null,
      2,
    ),
  );
});
```

```json
{
  "message": "Request failed with status 418",
  "query": "den haag",
  "source": "autocomplete",
  "provider": "OpenStreetMap"
}
```

### geosearch/providerchange

Fired when another provider is picked in the select, or with `selectProvider`. `provider` is the same as `getSelectedProvider()` returns.

```js
map.on('geosearch/providerchange', ({ provider }) => {
  const { index, label } = provider;
  console.log(JSON.stringify({ index, label }, null, 2));
});
```

```json
{
  "index": 1,
  "label": "Photon"
}
```

For the "All" option it's `{ "index": "all", "label": "All" }`.
