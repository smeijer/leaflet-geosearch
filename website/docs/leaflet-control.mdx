# Leaflet Control

To show the search control on your leaflet map, add the `SearchControl` to the leaflet map

<Map provider="OpenStreetMap" />

```js
import { SearchControl, OpenStreetMapProvider } from 'leaflet-geosearch';

const searchControl = new SearchControl({
  provider: new OpenStreetMapProvider(),
  style: 'bar',
});

map.addControl(searchControl);
```

## Style

<Map provider="OpenStreetMap" controlOptions={{ style: 'button' }} />

```js
import { SearchControl, OpenStreetMapProvider } from 'leaflet-geosearch';

const searchControl = new SearchControl({
  style: 'button',
  provider: new OpenStreetMapProvider(),
});

map.addControl(searchControl);
```

import { SearchControl, OpenStreetMapProvider } from 'leaflet-geosearch';

## Several providers

With `providers` instead of `provider`, a select left of the input lets the user pick the provider to search with, or search all of them at once. In that case every suggestion shows the name of its provider. Picking another provider searches the typed text again.

<Map providers={['OpenStreetMap', 'Photon', 'Esri']} />

```js
import {
  SearchControl,
  OpenStreetMapProvider,
  PhotonProvider,
  EsriProvider,
} from 'leaflet-geosearch';

const searchControl = new SearchControl({
  providers: [
    { label: 'OpenStreetMap', provider: new OpenStreetMapProvider() },
    { label: 'Photon', provider: new PhotonProvider() },
    { label: 'Esri', provider: new EsriProvider() },
  ],
  allProvidersLabel: 'All', // false leaves the "all" option out
  style: 'bar',
});

map.addControl(searchControl);
```

The labels are only shown to the user, so they can be in any language. When one provider fails while searching all of them, the others still show their results.

### Falling back to another provider

`fallback` searches the next provider in the list when the selected one fails (`'error'`), or also when it finds nothing (`'empty'`). With the select hidden, the user sees a single search box that keeps working when the first provider is down:

```js
const searchControl = new SearchControl({
  providers: [
    { label: 'OpenStreetMap', provider: new OpenStreetMapProvider() },
    { label: 'Photon', provider: new PhotonProvider() },
  ],
  showProviderSelect: false,
  allProvidersLabel: false,
  fallback: 'error',
});
```

### From code

```js
searchControl.selectProvider(1); // the index in providers, or 'all'
searchControl.getSelectedProvider(); // { index: 1, label: 'Photon', provider }
searchControl.setProviderSelectVisible(false);

map.on('geosearch/providerchange', ({ provider }) => {
  console.log(`searching with ${provider.label}`);
});
```

`resultFormat`, `popupFormat` and the events also get the provider that found a result, e.g. `resultFormat: ({ result, provider }) => ...`.

## Options

| Option                   | Type                                      | Default                                            | Description                                                                                                                       |
| ------------------------ | ----------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `provider`               | `Provider`                                | (required, or `providers`)                         | The provider to search with.                                                                                                      |
| `providers`              | `{ label, provider }[]`                   |                                                    | Several providers to choose from, see above.                                                                                      |
| `showProviderSelect`     | `boolean`                                 | `true`                                             | Show the provider select (with more than one provider).                                                                           |
| `allProvidersLabel`      | `string \| false`                         | `'All'`                                            | The select option that searches all providers. `false` leaves it out.                                                             |
| `providerSelectLabel`    | `string`                                  | `'Search with'`                                    | Accessible name of the provider select.                                                                                           |
| `fallback`               | `false \| 'error' \| 'empty'`             | `false`                                            | Search the next provider when the selected one fails, or also when it finds nothing.                                              |
| `style`                  | `'button' \| 'bar'`                       | `'button'`                                         | A button that opens the search box, or a bar that is always visible.                                                              |
| `position`               | `ControlPosition`                         | `'topleft'`                                        | Where Leaflet puts the control (`button` style).                                                                                  |
| `autoComplete`           | `boolean`                                 | `true`                                             | Search while typing and show suggestions.                                                                                         |
| `autoCompleteDelay`      | `number`                                  | `250`                                              | Milliseconds to wait after the last keystroke before searching.                                                                   |
| `minQueryLength`         | `number`                                  | `1`                                                | Characters to type before autocomplete searches. Pressing enter always searches.                                                  |
| `maxSuggestions`         | `number`                                  | `5`                                                | How many suggestions to show.                                                                                                     |
| `cacheSize`              | `number`                                  | `0`                                                | How many search results to keep in memory, so the same text isn't requested twice. `0` turns the cache off.                       |
| `showResultListOnSubmit` | `boolean`                                 | `false`                                            | Enter shows the results to pick from instead of the first one. With `autoComplete: false` the provider is only searched on enter. |
| `requeryOnSelect`        | `boolean`                                 | `false`                                            | Search the provider again when a suggestion is picked, even if it has coordinates.                                                |
| `showMarker`             | `boolean`                                 | `true`                                             | Show a marker at the result.                                                                                                      |
| `showPopup`              | `boolean`                                 | `false`                                            | Open a popup on the marker.                                                                                                       |
| `marker`                 | `MarkerOptions`                           | `{ icon: new L.Icon.Default(), draggable: false }` | Options for the marker. Missing keys keep their default.                                                                          |
| `maxMarkers`             | `number`                                  | `1`                                                | How many result markers stay on the map.                                                                                          |
| `popupFormat`            | `({ query, result, provider }) => string` | the escaped label                                  | The popup content (html).                                                                                                         |
| `resultFormat`           | `({ result, provider }) => string`        | the escaped label                                  | The text of a suggestion (html).                                                                                                  |
| `retainZoomLevel`        | `boolean`                                 | `false`                                            | Only pan to the result, keep the zoom level.                                                                                      |
| `zoomLevel`              | `number`                                  | `18`                                               | Zoom level for results without bounds.                                                                                            |
| `animateZoom`            | `boolean`                                 | `true`                                             | Animate moving to the result.                                                                                                     |
| `updateMap`              | `boolean`                                 | `true`                                             | Move the map to the result.                                                                                                       |
| `autoClose`              | `boolean`                                 | `false`                                            | Close the control after a result is picked.                                                                                       |
| `keepResult`             | `boolean`                                 | `false`                                            | Keep the picked result in the search box.                                                                                         |
| `searchLabel`            | `string`                                  | `'Enter address'`                                  | Placeholder of the search box.                                                                                                    |
| `clearSearchLabel`       | `string`                                  | `'Clear search'`                                   | Label of the reset button.                                                                                                        |
| `notFoundMessage`        | `string`                                  | `''`                                               | Shown when a search finds nothing.                                                                                                |
| `messageHideDelay`       | `number`                                  | `3000`                                             | Milliseconds before the message hides.                                                                                            |
| `resetButton`            | `string`                                  | `'×'`                                              | Text of the reset button.                                                                                                         |
| `classNames`             | `object`                                  | see source                                         | Extra class names per element. Missing keys keep their default.                                                                   |

## Events

| Event                      | Payload                              | When                                                          |
| -------------------------- | ------------------------------------ | ------------------------------------------------------------- |
| `geosearch/showlocation`   | `{ location, marker, provider }`     | A result is shown on the map.                                 |
| `geosearch/marker/dragend` | `{ location, event }`                | A draggable result marker was moved.                          |
| `geosearch/error`          | `{ error, query, source, provider }` | A search failed. `source` is `'autocomplete'` or `'submit'`.  |
| `geosearch/providerchange` | `{ provider }`                       | Another provider was picked, by the user or `selectProvider`. |

```js
map.on('geosearch/showlocation', ({ location }) => console.log(location.label));
```
