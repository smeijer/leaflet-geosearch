# Security Policy

## Supported Versions

Security fixes go into the latest major version.

| Version | Supported |
| ------- | --------- |
| 5.x     | Yes       |
| < 5.0   | No        |

## Reporting a Vulnerability

Please don't open a public issue for a security problem. Report it privately on GitHub instead: go to the [Security tab](https://github.com/smeijer/leaflet-geosearch/security) and click "Report a vulnerability", or use [this link](https://github.com/smeijer/leaflet-geosearch/security/advisories/new).

Include the version, what an attacker could do, and the steps or code to reproduce it. We'll reply within a week, and once it's fixed we'll publish an advisory and credit you, unless you'd rather not be named.

Problems in a geocoding service itself (OpenStreetMap, Google, Esri and the others) should be reported to that service.
